## 🚀 Cómo ver y ejecutar la presentación

Dado que la presentación incluye integración de videos en tiempo real y tipografías externas, se recomienda ejecutarla mediante un servidor local (para evitar restricciones del navegador al abrir archivos locales de tipo `file://`).

### Opción 1: Servidor local con Python (Recomendado y rápido)
1. Asegúrate de tener Python instalado en tu computadora.
2. Abre una terminal (CMD o PowerShell en Windows, Terminal en Mac/Linux) en la carpeta donde descargaste el archivo.
3. Ejecuta el siguiente comando:
   ```bash
   python -m http.server 8000
